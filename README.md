# Cyber Project

## Description
The Cyber Project is an advanced web application designed to manage user authentication via LDAP and handle file operations securely within an organization. It provides a robust dashboard for managing personal and shared files, including functionalities for uploading, downloading, and deleting files. This project uses React for the frontend and Node.js with Express for the backend, featuring HTTPS setup for secure communication.

## Key Features
- **LDAP Authentication**: Secure authentication mechanism using LDAP.
- **File Management**: Upload, download, and delete personal and shared files.
- **Role-Based Access Control**: Different levels of access and actions based on user roles.
- **Secure Communication**: HTTPS setup for secure data transmission.
- **Responsive UI**: A modern, responsive dashboard built with React.
